Política de Privacidade

Última atualização: 21 de Junho de 2026

Esta política descreve como o GB Code coleta, utiliza e protege dados no contexto do LemeIA CRM, incluindo as integrações com a API do WhatsApp (Meta) e com a API do Google Calendar.

1. Dados Coletados via WhatsApp

Coletamos apenas as informações necessárias enviadas via WhatsApp, como:

  • Número de telefone;
  • Nome de exibição do perfil;
  • Conteúdo das mensagens enviadas pelo usuário em contexto de atendimento.

2. Dados Coletados via Google Calendar

Quando o usuário (cliente que utiliza o LemeIA CRM) conecta sua conta Google, utilizamos a API do Google Calendar exclusivamente na tela de Agendamento de Compromissos do CRM, para:

  • Criar eventos de compromissos e demonstrações agendadas com os clientes do usuário;
  • Editar ou cancelar eventos previamente criados pelo próprio LemeIA CRM quando um agendamento é alterado;
  • Ler informações básicas de data/horário dos eventos criados pelo CRM para evitar conflitos de agenda.

Não acessamos, lemos ou armazenamos o conteúdo de eventos da agenda do usuário que não tenham sido criados pelo próprio LemeIA CRM. Os dados de calendário são utilizados em tempo real para a funcionalidade de agendamento e não são vendidos, compartilhados ou utilizados para fins de publicidade.

3. Finalidade do Uso

Os dados são utilizados exclusivamente para automação de atendimento, agendamento de compromissos e histórico comercial dentro do LemeIA CRM. Não vendemos esses dados a terceiros sob nenhuma hipótese.

4. Compartilhamento com Terceiros

As mensagens trafegam pela infraestrutura da Meta (WhatsApp Cloud API) e os eventos de agenda trafegam pela infraestrutura do Google (Google Calendar API), estando sujeitos também aos termos de serviço e políticas de privacidade dessas plataformas.

5. Uso de Dados do Google de Acordo com a Google API Services User Data Policy

O uso, por parte do LemeIA CRM, dos dados obtidos por meio das APIs do Google está em conformidade com a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado ("Limited Use"). Os dados de calendário não são utilizados para exibir anúncios, não são vendidos e não são transferidos a terceiros, exceto quando necessário para a operação da funcionalidade de agendamento ou exigido por lei.

6. Seus Direitos

O usuário pode, a qualquer momento, revogar o acesso do LemeIA CRM à sua conta Google em myaccount.google.com/permissions, e solicitar a exclusão de seus dados de nossa base entrando em contato pelo e-mail: contato@gbcode.com.br.

7. Segurança

Empregamos medidas técnicas e organizacionais rígidas para proteger as informações processadas em nossos servidores.

8. Termos de Serviço

O uso do LemeIA CRM está sujeito também aos nossos Termos de Serviço.
