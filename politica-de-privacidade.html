Política de Privacidade

Última atualização: 17 de Fevereiro de 2026

Esta política descreve como o GB Code coleta e utiliza dados através da integração com a API do WhatsApp.

1. Dados Coletados

Coletamos apenas as informações necessárias enviadas via WhatsApp, como:

  • Número de telefone;
  • Nome de exibição do perfil;
  • Conteúdo das mensagens enviadas pelo usuário.

2. Finalidade do Uso

Os dados são utilizados exclusivamente para automação de atendimento. Não vendemos esses dados a terceiros.

3. Compartilhamento com a Meta

As mensagens trafegam pela infraestrutura da Meta (WhatsApp Cloud API) e estão sujeitas aos termos de serviço da própria plataforma.

4. Seus Direitos

O usuário pode, a qualquer momento, solicitar a exclusão de seus dados de nossa base entrando em contato pelo e-mail: barbieri_lgb@hotmail.com.

5. Segurança

Empregamos medidas técnicas para proteger as informações processadas em nossos servidores.
